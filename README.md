## 📚 About This Section

This section is dedicated to learning **PyTorch and Deep Learning** through structured courses, practical implementations, and hands-on exercises.

The main goal is to organize course materials, reproduce examples, solve exercises, and provide reusable code and learning resources for anyone interested in developing their PyTorch skills.

We will follow multiple learning resources, document important concepts, and implement practical projects along the way.

## 🎓 Learning Roadmap

### 01. PyTorch for Deep Learning — Joseph Portilla

<kbd>COMPLETED</kbd> <img src="https://img.shields.io/badge/Level-Intermediate%20to%20Advanced-orange?style=flat-square" />

A short but highly intensive course that moves quickly through Deep Learning concepts and their practical implementation using PyTorch.

Although sequential model implementation is not covered in much detail, the course provides a useful overview of several important concepts and techniques.

**📌 Topics Covered**

- Artificial Neural Networks (ANNs)
- ReLU Activation Function
- Dropout and Regularization
- Convolutional Neural Networks (CNNs)
- Dataset and DataLoader
- Model Training and Evaluation

**💻 Practical Implementations**

| Project | Description |
|:---|:---|
| MNIST | Handwritten Digit Classification |
| CIFAR-10 | Image Classification |
| Custom Dataset | Loading local images using PyTorch DataLoader |

**📝 Course Review**

An intensive introduction to PyTorch, with a fast learning pace and a good range of practical examples. Overall, it is a suitable resource for learners who already have some familiarity with Python and want to move toward more advanced Deep Learning concepts.
