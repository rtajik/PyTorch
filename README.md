## 📚 About This Section

This repository is dedicated to learning **PyTorch and Deep Learning** through structured courses, practical implementations, and hands-on exercises.

The main goal is to organize course materials, reproduce examples, solve exercises, and develop reusable code and learning resources for anyone interested in building practical PyTorch skills.

Multiple learning resources will be followed throughout this journey. Important concepts will be documented, implementations will be reproduced and improved, and practical projects will be developed along the way.

The first course in this learning journey was Jose Portilla's PyTorch course, which has now been completed.

This is a relatively short but intensive course that moves quickly through Deep Learning concepts and their practical implementations.

**📌 Topics Covered**

- Artificial Neural Networks (ANNs)
- Activation Functions (ReLU)
- Dropout and Regularization
- Convolutional Neural Networks (CNNs)
- Dataset and DataLoader
- Model Training and Evaluation

**💻 Practical Implementations**

| Project | Description |
|:---|:---|
| MNIST | Handwritten Digit Classification |
| CIFAR-10 | Image Classification |
| Custom Dataset | Loading local images using PyTorch DataLoader |

**📝 Course Review**

An intensive introduction to PyTorch with a fast learning pace and a good range of practical examples.

Although sequential model implementation is not covered in much detail, the course provides a good overview of several important Deep Learning concepts and practical techniques.

Overall, it is a suitable resource for learners who already have some familiarity with Python and want to move toward more advanced Deep Learning concepts.
